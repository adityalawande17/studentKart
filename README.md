# StudentKart

A centralized platform providing **academic materials, interview preparation resources, and career roadmaps** in one place — helping students access everything they need without confusion.

 **Live Demo:** https://student-kart.vercel.app/

---

## Features

### User Authentication
- Secure login and signup functionality

### Role-Based Access Control
- **Admin:** Upload and manage resources  
- **Users:** Browse and access content  

### Organized Resources
- Categorized academic materials  
- Interview preparation guides  
- Career roadmaps  

### Scalable Backend
- RESTful APIs integrated with MongoDB for efficient data management

## Project Overview

StudentKart is designed to simplify the student journey by bringing together:
- Academic resources  
- Placement preparation materials  
- Structured career guidance  

All in one easy-to-use platform.
